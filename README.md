# Python Programming Mini Projects

This repository contains a collection of small Python programming projects developed as part of a mini-project series. Each project focuses on practical Python programming concepts such as file handling, data management, calculations, and basic application development.

## Projects

| No. | Project | Description |
|---|---|---|
| 1 | **Student Record Manager** | Add, view, search, update, and delete student records. |
| 2 | **Quiz Application** | Load questions, calculate scores, display results, and save score history. |
| 3 | **Expense Tracker** | Record expenses by date and category and show totals and monthly summaries. |
| 4 | **Inventory Manager** | Manage products, track stock movements, search products, and flag low stock. |
| 5 | **Attendance Tracker** | Register trainees, mark attendance, calculate percentages, and export reports. |
| 6 | **Task Manager** | Create tasks, set deadlines and priorities, update status, and save task records. |

## Repository Structure

Each project has its own folder containing:

- Source code
- Project-specific `README.md`
- Software Requirements Specification (SRS)
- Required data/configuration files

## Technologies

- **Language:** Python
- **Data Storage:** CSV / JSON
- **GUI:** Basic frontend where applicable
- **IDE:** VS Code
